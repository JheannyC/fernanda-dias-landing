# Fernanda Dias Makeup

Landing page feita com Vue 3, Vite e Tailwind CSS.

## Executar localmente

Pré-requisitos: Node.js 18 ou superior e npm.

1. Abra um terminal na pasta do projeto.
2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Abra no navegador o endereço exibido no terminal (por padrão, `http://localhost:5173`).
5. Para encerrar o servidor, pressione `Ctrl+C` no terminal.

## Compilar para produção

```bash
npm run build
```

Os arquivos prontos para publicação serão gerados na pasta `dist/`.

Para testar essa versão localmente:

```bash
npm run preview
```
